# Maestro E2E

실제 폰(또는 에뮬레이터)에서 앱을 눌러 보며 확인합니다. 흐름은 로그인된 상태에서 시작하고 비밀번호를 넣지 않습니다.

| 흐름 | 확인하는 것 | 준비 |
|---|---|---|
| `home-tabs.yaml` | 하단 4탭(홈·여행·저장·MY), 내 코스 필터, 나의 여행 지도 | 로그인 |
| `travel-map.yaml` | 지도 핀 → 여행기 보기 | 발행한 여행기 1개 이상 |
| `friends.yaml` | 친구 옵션 → 친구의 여행 지도 | 친구 1명 이상 |
| `diary-edit.yaml` | 여행기 수정(쓰기 → 설정 → 완료) 후 되돌리기 | `-e DIARY_ID=<내 여행기> -e ORIGINAL_BODY=<지금 본문>` |
| `perf/browse-tabs.yaml` | Flashlight 성능 측정용 탭 이동 | 릴리스 빌드 |

```bash
npm run test:e2e
```

- `common/`은 다른 흐름이 부르는 조각이라 단독으로 돌리지 않습니다. `perf/`도 기본 실행에서 빠집니다.
- 앱이 켜지는 중에 딥 링크를 보내면 홈에 머무르므로 `common/launch.yaml`이 홈이 뜰 때까지 기다립니다.
- "홈" 탭은 시스템 내비게이션 바의 "홈" 버튼과 라벨이 같아 흐름에서 누르지 않습니다.
